# CocoMUD

CocoMUD est un client MUD qui se veut simple et accessible avec un lecteur d'écran. Son but est de proposer autant de fonctionnalités que n'importe quel client MUD disponible, mais en étant plus accessible. Une des fonctionnalités basiques du client est un Text-To-Speech (TTS) permettant d'envoyer du texte pour être lu par le lecteur d'écran, ou affiché par une plage braille.

## Utiliser CocoMUD

Pour télécharger le client CocoMUD, rendez-vous sur [la page de téléchargement](download.md). Si c'est la première fois que vous utilisez CocoMUD, vous pourriez vouloir lire [les premiers pas avec CocoMUD](basics.md) pour apprendre à utiliser les fonctionnalités basiques du client.

## Fonctionnalités basiques

Les fonctionnalités suivantes servent de base à la planification du développement du client, en suivant sa feuille de route (road map).

- Un client MUD avec un système réseau stable.
- Un client accessible avec la plupart des lecteurs d'écran.
- Un client MUD portable sous Windows, Linux et Mac OS.
- Une interface traduite en plusieurs langues.
- Un mécanisme simple mais puissant pour personnaliser l'expérience utilisateur, avec [des alias](alias.md), [des macros](macros.md), [des triggers](triggers.md) et bien d'autres choses.

- Vous pouvez [ouvrir un ticket](https://github.com/vincent-lg/cocomud/issues) sur GitHub, si vous avez un compte GitHub (sinon, [cliquez ici pour en créer un](https://github.com/signup)).
- Vous pouvez vous abonner et écrire à la [liste de diffusion de CocoMUD](https://www.freelists.org/list/cocomud). Vous n'avez pas besoin de compte, mais devrez vous abonner en entrant votre adresse e-mail.
